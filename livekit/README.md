# خادم LiveKit ومساعد الذكاء الاصطناعي Jarvis (المشروع المدمج)

هذا المستودع هو نتاج دمج متكامل لعدة مشاريع معاً لتشكيل بيئة كاملة لإنشاء وتشغيل مساعدات صوتية ذكية تعتمد على الذكاء الاصطناعي (Voice AI Agents) بالوقت الفعلي.

يحتوي هذا المستودع الموحد على المكونات الثلاثة الرئيسية التالية:

---

## 1. خادم LiveKit الأساسي (`/livekit`)
LiveKit هو محرك مفتوح المصدر (WebRTC SFU) مبني بلغة `Go`. وظيفته هي توجيه الصوت والفيديو والبيانات في الوقت الفعلي بين جميع المشاركين (سواء كانوا مستخدمين بشريين عبر المتصفح أو وكلاء ذكاء اصطناعي).

### الهيكل التنظيمي للمجلد:
```text
livekit/
├── build/         # المخرجات والملفات المجمعة (Build outputs)
├── cmd/           # نقاط الدخول لتشغيل الخادم (مثل livekit-server)
├── pkg/           # الحزم البرمجية الأساسية (Routing, RTC, Services)
├── docker/        # ملفات إعداد حاويات Docker
├── README.md      # التوثيق الخاص بالخادم
└── go.mod         # ملف إدارة الاعتمادات للغة Go
```

### الأمر الأكثر استخداماً:
لتشغيل الخادم في وضع التطوير (والذي يولد مفاتيح افتراضية للتجربة):
```bash
cd "C:\yamk-jarvis-agent\livekit"
livekit-server --dev
```

---

## 2. مساعد Jarvis الصوتي (`/jarvis`)
هذا هو "عقل" المساعد الصوتي، مبني باستخدام `Python` ويعتمد على إطار عمل `LiveKit Agents`. يقوم بالاستماع إلى صوت المستخدم، تحويله إلى نص (STT)، تمريره إلى نماذج لغوية ضخمة مثل Gemma للرد عليه (LLM)، ثم تحويل الرد النصي إلى صوت (TTS) ليسمعه المستخدم.

### الهيكل التنظيمي للمجلد:
```text
jarvis/
├── src/
│   └── agent.py   # الكود المصدري الرئيسي الذي يحتوي على منطق المساعد الصوتي
├── .env.local     # متغيرات البيئة (مفاتيح API وروابط الاتصال بخادم LiveKit)
├── uv.lock        # ملف تأمين إصدارات المكتبات المستخدمة
├── README.md      # التوثيق الخاص بالمساعد الصوتي
└── pyproject.toml # إعدادات مشروع بايثون والاعتمادات
```

### الأمر الأكثر استخداماً:
لتشغيل المساعد الصوتي وربطه بالخادم:
```bash
cd "C:\yamk-jarvis-agent\jarvis"
uv run python src/agent.py dev
```
*(تأكد من إعداد ملف `.env.local` ليحتوي على `LIVEKIT_URL` والمفاتيح الصحيحة قبل التشغيل)*

---

## 3. واجهة المستخدم الأمامية لـ Jarvis (`/jarvis/frontend`)
تطبيق ويب متطور يمثل واجهة المستخدم (Frontend)، مبني باستخدام `React` و `Next.js`. يتيح للمستخدمين الاتصال بغرفة LiveKit، والتحدث مع المساعد الصوتي (Jarvis) عبر الميكروفون، مع توفير مؤثرات بصرية للصوت (Audio Visualizers) بأشكال مختلفة (Bar, Wave, Aura...).

### الهيكل التنظيمي للمجلد:
```text
jarvis/frontend/
├── app/           # موجه صفحات Next.js (الصفحات، واجهات الـ API)
├── components/    # مكونات واجهة المستخدم (أزرار التحكم، المؤثرات البصرية)
├── public/        # الأصول الثابتة (الصور، الأيقونات، الشعارات)
├── package.json   # الاعتمادات البرمجية (NPM Dependencies)
├── tailwind.config.ts # إعدادات تصميم واجهة المستخدم باستخدام TailwindCSS
├── .env.local     # متغيرات البيئة الخاصة بالواجهة الأمامية
└── README.md      # التوثيق الخاص بواجهة المستخدم
```

### الأمر الأكثر استخداماً:
لتشغيل خادم التطوير للواجهة الأمامية:
```bash
cd "C:\yamk-jarvis-agent\jarvis\frontend"
pnpm dev
```
بمجرد التشغيل، يمكنك فتح المتصفح على الرابط `http://localhost:3000` للبدء في استخدام المساعد.
